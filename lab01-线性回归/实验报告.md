## （一）数据与方法

### 1. 数据来源与规模

实验用 scikit-learn 内置的 \texttt{load\_diabetes()}，不需要联网下载。数据有 442 个样本、10 个特征，目标是患者一年后病情进展的定量指标。十个特征依次是 age、sex、bmi、bp、s1 到 s6。

这份数据只作教学用，不能当医学诊断依据。加载后检查：$X$ 形状 $(442, 10)$，$y$ 形状 $(442,)$。用 \texttt{np.isfinite} 检查非有限值，全部为 True，没有缺失也没有异常数值。

### 2. 固定划分

按任务书固定参数划分，random\_state 固定为 42，别人重跑能得到相同的划分：

\begin{verbatim}
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=42)
\end{verbatim}

得到训练集 $X_{tr}\in\mathbb{R}^{309\times 10}$、$y_{tr}\in\mathbb{R}^{309}$，测试集 $X_{te}\in\mathbb{R}^{133\times 10}$、$y_{te}\in\mathbb{R}^{133}$。$X$ 和 $y$ 一起传进划分函数，保证同一条记录的特征和目标落在同一侧。

### 3. 预处理的拟合范围

训练集上调用 \texttt{fit\_transform}，测试集上只调用 \texttt{transform}：

\begin{verbatim}
Xtr_s = scaler.fit_transform(Xtr)   # 在训练集上求均值和标准差，并转换
Xte_s = scaler.transform(Xte)       # 测试集沿用训练集的参数
\end{verbatim}

$X_{tr}^{s}$ 每列均值约为 0（量级 $10^{-16}$），标准差为 1，标准化确实生效了。测试集不能再 fit 一次，均值和标准差属于模型参数，只能用训练集估计。

测试集要扮演将来才会见到的数据，沿训练集的参数去减、去除，评估出来的分数才接近真实泛化表现。若在测试集上重新 fit，测试集的分布信息就漏进了预处理，分数会偏乐观。目标 $y$ 不做标准化，因为 MSE 和 RMSE 要保留原来的量纲才有意义。

有一点要说明：\texttt{load\_diabetes()} 的特征在出厂时已经用全部 442 个样本做过预中心化，并按“标准差 $\times\sqrt{n}$”缩放。严格讲这份内置数据本身带了轻微的全局信息，不能声称原始数据完全没有泄漏，这是教学数据的固有限制。

在训练集上再做一次 StandardScaler 是为了走规范流程，并不是最小二乘必需——普通最小二乘对特征的线性缩放是不变的。

### 4. BMI 的尺度

任务 4a 和图 2 用的是默认 bmi 列，数值范围约 $\pm 0.05$，已经过预中心化和缩放，不是原始的 $\mathrm{kg/m^2}$，所以图 2 横轴只能标“默认预缩放尺度”。4a 里特意不再对 BMI 标准化，保留默认尺度，这样公式算出的结果和 sklearn 一元模型用的是同一份数据。

## （二）任务 4a：一元最小二乘的推导

### 1. 模型

只用一个特征 $x$（训练集的 BMI 列）预测 $y$。对第 $i$ 个样本：

$$\hat{y}_i = w_0 + w_1 x_i$$

$w_1$ 是斜率，$w_0$ 是截距。单个样本的残差写作：

$$e_i = y_i - \hat{y}_i = y_i - w_0 - w_1 x_i$$

### 2. 损失函数

最小二乘的准则是让残差平方和最小：

$$L(w_0, w_1) = \sum_{i=1}^{n} \left( y_i - w_0 - w_1 x_i \right)^2$$

用平方而不是绝对值，是因为平方函数处处可导，求导后得到线性方程组，有闭式解；绝对值在零点不可导，只能迭代求解。

### 3. 两个偏导方程

$L$ 是 $w_0$ 和 $w_1$ 的二次函数，最小值点处两个偏导同时为零：

$$\frac{\partial L}{\partial w_0} = -2 \sum_{i=1}^{n} \left( y_i - w_0 - w_1 x_i \right) = 0$$

$$\frac{\partial L}{\partial w_1} = -2 \sum_{i=1}^{n} x_i \left( y_i - w_0 - w_1 x_i \right) = 0$$

两式同除 $-2$ 并展开，得到正规方程组：

$$n\, w_0 + w_1 \sum_{i=1}^{n} x_i = \sum_{i=1}^{n} y_i$$

$$w_0 \sum_{i=1}^{n} x_i + w_1 \sum_{i=1}^{n} x_i^2 = \sum_{i=1}^{n} x_i y_i$$

### 4. 解出斜率与截距

由第一式解出 $w_0$：

$$w_0 = \frac{1}{n}\sum_{i=1}^{n} y_i - w_1 \cdot \frac{1}{n}\sum_{i=1}^{n} x_i$$

写成均值形式更直观，回归直线必然过样本均值点：

$$w_0 = \bar{y} - w_1 \bar{x}$$

把 $w_0$ 代回第二式消掉它，整理后得到斜率：

$$w_1 = \frac{\sum_{i=1}^{n} \left( x_i - \bar{x} \right)\left( y_i - \bar{y} \right)}{\sum_{i=1}^{n} \left( x_i - \bar{x} \right)^2}$$

其中 $\bar{x}$ 与 $\bar{y}$ 为样本均值：

$$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i , \qquad \bar{y} = \frac{1}{n}\sum_{i=1}^{n} y_i$$

斜率的含义是 $x$ 与 $y$ 的样本协方差除以 $x$ 的样本方差。

### 5. 成立条件

分母不能为零。$\sum (x_i-\bar{x})^2 > 0$ 要求 $x$ 在训练集里有变化；若所有 $x_i$ 相同，斜率无定义，回归退化成 $\hat{y}=\bar{y}$。本次 BMI 各不相同，分母实测 $0.7112660671289088$，远大于零。

模型设定要对。公式假设真实关系是线性的、误差项均值为零。真实关系若不是线性的，得到的只是一条线性近似。

误差项需满足不相关且同方差，这是最小二乘估计具备最小方差（高斯–马尔可夫定理）的前提。条件不满足时公式照样能算，但不再是最优估计，也不能直接用于统计推断。

闭式解只保证训练集上残差平方和最小，与测试集表现无关。

## （三）任务 4b：多元最小二乘的推导与实现

### 1. 模型与增广矩阵

这次用全部 10 个标准化后的特征。对第 $i$ 个样本：

$$\hat{y}_i = \theta_0 + \theta_1 x_{i1} + \theta_2 x_{i2} + \cdots + \theta_{10} x_{i,10}$$

为了把截距 $\theta_0$ 也装进统一的矩阵形式，在 $X$ 左侧补一列全 1：

$$\mathbf{X}_b = [\mathbf{1}, X] \in \mathbb{R}^{n\times(p+1)}, \qquad \boldsymbol{\theta} = (\theta_0,\theta_1,\dots,\theta_p)^{\mathsf{T}} \in \mathbb{R}^{p+1}$$

本次 $n=309$、$p=10$，所以 $\mathbf{X}_b$ 的形状是 $(309, 11)$。补这一列的好处是截距变成普通权重，模型统一写成 $\mathbf{X}_b\boldsymbol{\theta}$，求导时不用为截距单独处理。

### 2. 损失函数

用矩阵范数写残差平方和：

$$L(\boldsymbol{\theta}) = \left\| \mathbf{X}_b \boldsymbol{\theta} - \mathbf{y} \right\|^2 = \left( \mathbf{X}_b \boldsymbol{\theta} - \mathbf{y} \right)^{\mathsf{T}} \left( \mathbf{X}_b \boldsymbol{\theta} - \mathbf{y} \right)$$

展开得：

$$L(\boldsymbol{\theta}) = \boldsymbol{\theta}^{\mathsf{T}} \mathbf{X}_b^{\mathsf{T}} \mathbf{X}_b \boldsymbol{\theta} - 2\, \boldsymbol{\theta}^{\mathsf{T}} \mathbf{X}_b^{\mathsf{T}} \mathbf{y} + \mathbf{y}^{\mathsf{T}} \mathbf{y}$$

$\mathbf{X}_b^{\mathsf{T}}\mathbf{X}_b$ 是半正定矩阵，因为对任意 $\boldsymbol{\theta}$ 都有 $\boldsymbol{\theta}^{\mathsf{T}}\mathbf{X}_b^{\mathsf{T}}\mathbf{X}_b\boldsymbol{\theta} = \|\mathbf{X}_b\boldsymbol{\theta}\|^2 \ge 0$。所以 $L(\boldsymbol{\theta})$ 是凸函数，一阶导数为零的点就是全局最小点，不存在陷入局部极小的问题。

### 3. 梯度与正规方程

对 $\boldsymbol{\theta}$ 求梯度，用到对称矩阵的 $\partial(\boldsymbol{\theta}^{\mathsf{T}}A\boldsymbol{\theta})/\partial\boldsymbol{\theta} = 2A\boldsymbol{\theta}$：

$$\nabla L(\boldsymbol{\theta}) = 2 \mathbf{X}_b^{\mathsf{T}} \left( \mathbf{X}_b \boldsymbol{\theta} - \mathbf{y} \right)$$

写成均方误差形式：

$$\nabla \mathrm{MSE}(\boldsymbol{\theta}) = \frac{2}{n} \mathbf{X}_b^{\mathsf{T}} \left( \mathbf{X}_b \boldsymbol{\theta} - \mathbf{y} \right)$$

令梯度为零，得到正规方程：

$$\mathbf{X}_b^{\mathsf{T}} \mathbf{X}_b \boldsymbol{\theta} = \mathbf{X}_b^{\mathsf{T}} \mathbf{y}$$

### 4. 解与成立条件

若 $\mathbf{X}_b^{\mathsf{T}}\mathbf{X}_b$ 可逆，最小二乘解为：

$$\hat{\boldsymbol{\theta}} = \left( \mathbf{X}_b^{\mathsf{T}} \mathbf{X}_b \right)^{-1} \mathbf{X}_b^{\mathsf{T}} \mathbf{y}$$

成立条件主要有三条。

第一，$\mathbf{X}_b$ 列满秩。$\mathrm{rank}(\mathbf{X}_b)=11$ 表示 11 列线性无关，等价于 $\mathbf{X}_b^{\mathsf{T}}\mathbf{X}_b$ 正定可逆，解唯一。本次实测 rank = 11，满足条件。若存在完全共线，$\mathbf{X}_b^{\mathsf{T}}\mathbf{X}_b$ 奇异，解不唯一，得删特征、加正则或者改用伪逆。

第二，样本量要够。$n = 309 \ge p+1 = 11$。

第三，数值上不宜显式求逆。代码里用 \texttt{np.linalg.lstsq}，它走 QR/SVD 分解。显式求逆要算 $(\mathbf{X}_b^{\mathsf{T}}\mathbf{X}_b)^{-1}\mathbf{X}_b^{\mathsf{T}}\mathbf{y}$，多一次矩阵乘法会放大舍入误差，$\mathbf{X}_b^{\mathsf{T}}\mathbf{X}_b$ 病态或奇异时还会直接失败。本次 10 个特征之间相关性不弱，条件数不算小，所以统一用 lstsq。

### 5. 与梯度下降的联系（任务 8 的依据）

任务 8 用迭代法解同一个问题。由上面的梯度公式可以写出：

$$\mathbf{g} = \nabla \mathrm{MSE}(\boldsymbol{\theta}) = \frac{2}{n}\mathbf{X}_b^{\mathsf{T}}\left(\mathbf{X}_b\boldsymbol{\theta}-\mathbf{y}\right), \qquad H = \nabla^2 \mathrm{MSE}(\boldsymbol{\theta}) = \frac{2}{n}\mathbf{X}_b^{\mathsf{T}}\mathbf{X}_b$$

MSE 是二次函数，所以 $H$ 是常数矩阵。它的最大特征值 $L = \lambda_{\max}(H) = 7.913641206973075$ 就是梯度的 Lipschitz 常数，取步长 $\eta = 1/L = 0.12636408119170903$ 可以保证收敛。

迭代式为 $\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} - \eta \mathbf{g}$，初值取 $b=\mathrm{mean}(y_{tr})$、$\mathbf{w}=\mathbf{0}$。

## （四）任务 4b：NumPy 多元类

\begin{verbatim}
class NumpyLinearRegression:
    def fit(self, X, y):
        Xb = np.column_stack((np.ones(X.shape[0]), X))
        weights, _, self.rank_, self.singular_ = np.linalg.lstsq(Xb, y, rcond=None)
        intercept_index = 0   # 补：第 0 列是全 1，对应截距
        coef_start = 1        # 补：第 1 个参数起是系数
        self.intercept_ = float(weights[intercept_index])
        self.coef_ = weights[coef_start:]
        return self

def numpy_predict(self, X):
    Xb = np.column_stack((np.ones(X.shape[0]), X))
    weights = np.concatenate(([self.intercept_], self.coef_))
    prediction = Xb @ weights    # 补：矩阵乘法
    return prediction
\end{verbatim}

\newpage# 结果分析

## （一）三个指标的含义

MSE 的表达式如下，单位是目标单位的平方，越小越好：

$$\mathrm{MSE} = \frac{1}{n}\sum_{i=1}^{n} e_i^2$$

RMSE 是 MSE 的平方根，与目标同量纲，可以直接读：平均偏离约 53 个单位。

$$\mathrm{RMSE} = \sqrt{\mathrm{MSE}}$$

$R^2$ 无量纲，衡量模型比“直接输出本集合均值”这条基线好多少：

$$R^2 = 1 - \frac{\sum_{i=1}^{n}\left(y_i-\hat{y}_i\right)^2}{\sum_{i=1}^{n}\left(y_i-\bar{y}\right)^2}$$

$R^2$ 为 1 表示完美预测，为 0 表示和均值基线持平，为负表示还不如直接猜均值。分母用的是被评估集合自身的均值，所以出现负值很正常。任务 7 里 degree = 3 的测试 $R^2$ 等于 $-91.94$ 就属于这种情况。

## （二）本次是否过拟合

训练 $R^2$ 0.5244，测试 $R^2$ 0.4773，差距 0.0471。测试 MSE 2821.75 甚至比训练 MSE 2924.05 还小一点。

这两点合起来说明没有强烈的过拟合信号。10 个特征配 309 个训练样本，自由度是够的。但测试 $R^2$ 只有 0.4773，模型只解释了约 47.7% 的目标方差，欠拟合才是主要问题：线性模型配这 10 个特征，本身就解释不了全部变化。

## （三）系数不能当因果解释

十特征模型的系数只表示“在其余特征固定的线性模型里，该特征与目标的条件相关方向和强度”。这份数据是观测数据，特征之间存在混杂和共线性，比如 s1 与 s2 彼此相关，bp 与其他血清指标也有关系。特征又都做过预缩放，不是医学单位。

bmi 的系数是正的 26.21，只能说在模型内控制住其余 9 个特征后，BMI 与病情进展正相关，推不出“提高 BMI 会导致病情恶化”。要谈因果得靠随机对照实验或专门的因果推断设计。

## （六）尺度、数值误差与泛化差距

建模前所有特征都在训练集上做了 z-score 标准化，均值 0、标准差 1。所以十特征模型的 bmi 系数 26.21 表示的是“BMI 每变化 1 个训练集标准差”的效果，不是原始单位。

4a 和图 2 用的是没再标准化的默认 bmi 列，斜率 988.42 和 26.21 数值上不可比，也不能互相换算。任务书特意提醒过，不要拿多元模型的 BMI 系数当图 2 的斜率。

数值误差方面，4a 斜率差约 $1.1\times 10^{-13}$，4b 最大预测差 $2.27\times 10^{-13}$，都在双精度浮点的舍入量级。机器精度约 $2.2\times 10^{-16}$，经过 $(\mathbf{X}_b^{\mathsf{T}}\mathbf{X}_b)$ 求逆这类运算放大到 $10^{-13}$ 是正常的。

所以 \texttt{np.allclose} 返回 True 只表示在给定容差 $\mathrm{rtol}=\mathrm{atol}=10^{-8}$ 内一致，不代表逐位相等。

泛化差距是 0.0471，不算大，模型是稳定的。真正的问题是欠拟合，测试 $R^2$ 只有 0.48。想再往上提，方向是引入非线性或者补充信息量更大的特征，而不是简单加正则。
